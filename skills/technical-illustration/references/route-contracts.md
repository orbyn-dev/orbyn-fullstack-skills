# Route contracts

Detail for the "Check the route" contracts in `SKILL.md`.

## Illustrated statecharts

Follow architect's [art contract](../../architect/references/illustrated-statecharts.md). Draw from the actual chart or trace records; architect retains state, guard, projection and verification ownership. Keep exact numbered paths and the plain/text fallback.

## Code-authored compositions

For arbitrary code-authored layered compositions, sampled tracks, rational clocks, vector/audio/media adapters or conditional 3D/simulation/effects, use the [code-driven motion contract](../../orbyn-ui-design/examples/spatial-review/motion/README.md). Use the existing UI owner for live takeover and the existing review writer for source-bound settings and decisions; no new authoring app or provider is required. Its Lottie input, Three.js profile and packaged adapters fall under the [code-only rule](code-only.md), so use them only when the user approves them.
